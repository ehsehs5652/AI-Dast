# Intigriti

Include the title, asset, vulnerability type, description, recorded reproduction
steps, and impact. Keep the endpoint identifiable in the asset or description
when supplied. The written sequence should be understandable without opening
an image. Recommendations and supporting attachments are optional. Preserve
redactions; do not add a testing IP, test account, severity, or CVSS vector that
was not present in the supplied evidence. Prefer English unless the supplied
program requirements specify otherwise.

Source checked 2026-09-09:
[Intigriti report guidance](https://kb.intigriti.com/en/articles/5379086-how-to-write-and-submit-a-good-report).
